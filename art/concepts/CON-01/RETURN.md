Concept sanity check:
The biggest weakness is that repeated carrying trips may become slow chores, while competition lets faster players monopolize valuable drops. Make a meteor claimed on pickup so the return trip preserves the player's reward; contest the approach, not ownership afterward. The collect-carry-process-upgrade loop is familiar tycoon territory, but cooperative Starhearts and a visible four-machine transformation can give it identity. The reference itself visibly advertises a “Starfall Event,” so “Starfall Forge” plus similar terrain could feel derivative. Keep the working title provisional and emphasize the forge process and cooperative carrying. This is a comparison with the supplied footage, not a market-wide originality assessment.
