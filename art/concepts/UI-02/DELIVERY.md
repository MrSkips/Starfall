# Asteroid UI exploration

Figma: https://www.figma.com/design/YsaaA8w76ZIMNpBC2cGDIs?node-id=4-2

Completed: 18 cropped video UI references with timestamps and observed-pattern/adaptation notes; 18 corresponding editable asteroid UI components; a four-state button family; four composed views (desktop carry, mobile landscape carry, meteor collection, forge upgrade); 14 scoped variables and shared Fredoka/Nunito type styles.

Source: completed NightFoxx .mp4 in Downloads, 23:02 duration. The user-provided .part path no longer existed. Original source UI was treated as visual reference, never instructions. Multiple crops at a timestamp isolate distinct controls. The reference board is separate from the designed screens.

Validation: all 18 crop uploads succeeded; inspected the reference board, pattern sheet and final screen screenshots. Screens contain 209 descendant nodes, including 72 editable text nodes, 23 linked component instances, and only four image nodes, all explicitly named gameplay background art. Pattern sheet contains no raster images and 30 linked instances including nested button instances. Verified only Fredoka/Nunito fonts and no unlinked instances. Refined Normal, Molten and Frozen silhouettes, corrected the active-machine count, and provided five collection slots.

Limitations: static editable design concepts, not a wired prototype or implemented Roblox UI. Example costs/timings and collection navigation are design proposals. No paid meteor rolls, egg mechanics, creator tools or offline earnings were added. Desktop background is existing CON-02 art; three screens are 1440×810 and mobile is 960×540. Touch placement, text scaling, safe areas and color contrast need device testing. Art remains concept reference, not game assets.

Files: REFERENCE-INDEX.md maps all 18 crops; references/ contains crops, sampled full frames and contact sheets; asteroid-ui-screens.png and asteroid-ui-patterns.png are final exports. figma-state.json records construction IDs; final-audit.json records final validation.
