# Reference color revision

Updated the existing Figma UI to the Steal an Egg video's palette, following Zack's request to use the same reference colors. Colors sampled from UIREF-05, UIREF-09 and UIREF-17: lime #6FFF10, cyan #19F0F5, red #E70002, panel #32333E. Supporting colors: white #FFFFFF, near-black border #080809, gold #FFE21B, purple #9A15E8. Values approximate compressed video pixels.

Shared components and all four composed views use the revised palette. Primary controls and progress fills are lime green, secondary/collection controls cyan, drop controls red, panels dark gray, labels white with dark heading outlines. Existing asteroid background art remains the gameplay context. Inspected the updated composed-screen export; fonts remain Fredoka/Nunito and all 23 screen instances remain linked.
